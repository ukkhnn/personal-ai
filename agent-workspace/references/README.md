# 조사 자료

오픈소스의 아키텍처, 확장 가능성, 라이선스 및 재사용 후보를 조사하는 폴더다.

초기 조사 대상은 PRD에 기재된 Happier, OpenCode, OpenHands, Letta Code, OpenClaw 등이다. 일부 공식 문서 기초 확인을 진행했으며, 실행 PoC나 기술 채택 결정은 없다.

각 조사에는 출처, 확인 날짜, 확인한 버전 또는 커밋, 요구사항 적합성, 제약과 추가 검증 항목을 기록한다.
