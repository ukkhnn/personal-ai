# 코드 실행 엔진 검토 메모

확인일: 2026-10-28. 상태: **OpenCode 우선 검증 확정 / PoC 미수행 / 최종 채택 미정**.

## 구분할 계층

- 자체 사용자 환경: 대화, 프로젝트·작업, 변경 확인, 추가 지시·중단·승인 화면.
- 자체 설정·운영 계층: Agent 프로필, 하네스·메모리 템플릿, worktree, 실행 기록과 Git 정책.
- 실행 엔진: 모델 호출과 도구 실행을 반복하고 작업 문맥을 유지하는 런타임.

자체 인터페이스와 기존 실행 엔진 사용은 함께 가능하다. 템플릿을 설정하는 기능과 실행 루프 전체를 자체 구현하는 것은 서로 다른 개발 범위다.

## 공식 문서에서 확인한 연결 방식

### Claude Agent SDK

Python·TypeScript 앱 안에서 Claude Code의 실행 루프와 파일·명령 도구, 세션, 권한, hooks를 활용할 수 있다. 시스템 프롬프트, skills, MCP 등의 설정 기능이 제공된다. 모델 API를 직접 호출하는 Client SDK와 구분한다.

- [Agent SDK 개요](https://code.claude.com/docs/en/agent-sdk/overview)
- [CLI의 비대화형 실행](https://code.claude.com/docs/en/headless)

구독 연결은 별도 검증 대상이다. 공식 개요는 사전 승인 없이 제3자 제품에 claude.ai 로그인이나 사용 한도를 제공하는 것을 허용하지 않는다고 안내하며 API 키 인증을 권고한다. 개인 도구에 대한 적용 범위나 구독 CLI 연결 가능성을 이 메모에서 확정하지 않는다.

### OpenCode Server / SDK

로컬 HTTP 서버와 SDK를 통해 세션·메시지·이벤트·중단·승인 응답 등을 연결할 수 있다. Agent별 프롬프트·모델·권한을 설정하고 다양한 모델 공급자 및 로컬 모델을 연결하는 구성을 제공한다.

- [Server](https://opencode.ai/docs/server/)
- [Agents](https://opencode.ai/docs/agents/)
- [Providers](https://opencode.ai/docs/providers/)

모델 공급자 지원을 해당 공급자의 월 구독 사용 가능성으로 해석하지 않는다. 실제 선정 버전을 고정하고 API·권한 규격과 재접속 동작을 검증해야 한다.

### 자체 실행 엔진

모델 API 위에 도구 실행, 컨텍스트 관리, 재시도, 중단·승인 및 복구를 직접 구현하는 선택지다. 제어 범위가 넓지만 구현·운영 책임도 커진다. 아직 채택하지 않았다.

## 확정한 검증 순서와 설정 범위

사용자가 OpenCode부터 검증하기로 확정했다 (DEC-010). 검증 결과를 보고 최종 채택 여부를 결정하며, Claude Agent SDK와 기존 구독 도구 연결은 비교·확장 후보로 유지한다.

첫 버전은 프롬프트·모델·스킬·도구·메모리·권한 설정까지 제공하고, 작업 순서 구성은 후속 확장한다 (DEC-009). 지속적인 실사용과 확장성을 기준으로 엔진을 평가한다.

## 구현 제안 — 세부 검증 필요

자체 화면·템플릿·프로젝트 운영 계층과 실행 엔진 연결을 분리한다.

하나의 작업 실행에는 하나의 주 실행 엔진을 할당하는 안으로 시작한다. 엔진을 서로 중첩하는 구성은 필요성이 입증되면 별도로 검토한다. 공통 템플릿과 엔진별 설정을 구분하고 지원되지 않는 설정은 표시한다.

## PoC에서 확인할 사항

- 서로 다른 worktree에서의 작업 분리와 설정 적용
- 코드 수정·테스트 성공 여부와 변경 결과 수집
- 승인 이벤트 전달과 프로젝트 설치·시스템 변경 권한 경계
- 추가 지시·대기열·중단 처리 및 재접속 후 상태 복원
- 프롬프트·skills·MCP·선택 메모리 주입 범위
- 인증 방식, 실제 이용 가능 모델 및 비용·구독 사용 범위
