# 하네스 템플릿 — 첫 버전 범위

기준: 2026-10-28, REQUIREMENTS v0.3 / DEC-009~011. 상태: **범위 확정 / 데이터 형식·구현 설계 대기**.

## 목적과 설정 범위

사용자가 재사용 가능한 Agent 실행 구성을 만들고 작업에 적용한다.

| 설정 | 첫 버전의 제공 범위 |
|---|---|
| 프롬프트 | 역할·작업 지침 설정 |
| 모델 | 연결된 실행 엔진에서 지원하는 모델 선택 |
| 스킬 | 사용할 스킬 선택·연결 |
| 도구 | 사용할 도구·MCP 연결 설정 |
| 메모리 | 사용할 메모리 범위·항목 선택과 실행 문맥에 적용 |
| 권한 | 자동 실행·승인 필요·허용하지 않는 작업 범위 설정 |

템플릿을 저장·선택·재사용하고 실행에 적용된 구성을 확인할 수 있어야 한다. 구체적인 편집 UI, 저장 형식, 스킬 작성 도구 및 메모리 검색 방식은 미정이다. 기존에 정한 병합·설치 승인 정책과 충돌하는 설정을 어떻게 제한할지도 상세 설계한다.

## 첫 버전에 포함하지 않는 기능

사용자가 계획 → 구현 → 리뷰 → 테스트 같은 작업 순서를 직접 구성하는 기능은 후속 확장이다. 코드 수정·테스트 등 기본 개발 흐름과 기존 엔진의 실행 루프는 첫 버전에 필요하다.

## 확장 설계 기준

- 자체 템플릿과 엔진별 변환·적용 코드를 분리한다.
- 지원하지 않는 설정을 표시하고 적용 실패를 숨기지 않는다.
- 설정 버전과 적용 기록을 남길 구조를 마련한다. 수정된 템플릿을 실행 중 작업에 적용하는 정책은 별도로 정한다.
- 향후 작업 순서의 각 단계에서 템플릿을 참조할 수 있도록 템플릿과 실행을 구분한다.
- 새 엔진·모델·도구·메모리를 추가할 때 기존 설정과 기록을 보존한다.

## OpenCode 우선 검증 항목

- [ ] 여섯 가지 설정이 실제 작업에 적용되는지 확인
- [ ] 템플릿을 서로 다른 세션·worktree에서 재사용
- [ ] 작업별 설정·메모리 범위가 다른 작업에 섞이지 않는지 확인
- [ ] 권한·승인 정책의 집행과 설정 오류 표시 확인
- [ ] 재접속 후 적용 설정과 작업 기록 조회
- [ ] 지원 차이·부족한 기능·보완 비용을 기록하고 최종 채택 판단

OpenCode가 모든 항목을 기본 제공한다고 가정하지 않는다. 자체 계층에서 보완할 부분과 엔진에 위임할 부분을 검증 결과로 정한다.
