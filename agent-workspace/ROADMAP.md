# 로드맵

기준: [PRD v0.1](PRD.md), 2026-10-28.

현재는 초기 기획 단계이며, 문서·작업 폴더 구성을 완료했다. 기술 조사와 구현은 아직 시작하지 않았다.

## Phase 0 — 사전 검증 및 기술 결정

- [ ] Happier, OpenCode, OpenHands, Letta Code, OpenClaw 조사
- [ ] 기기 간 핵심 세션 연속성 PoC
- [ ] Ollama 및 외부 API 연동 방식 검토
- [ ] 중앙 실행 및 원격 Worker 방식 검증
- [ ] 보안 및 라이선스 검토
- [ ] Fork / 자체 개발 비교와 실행 런타임 선택
- [ ] 데이터 모델, API, 세션 생명주기, Worker 통신 및 보안 상세 설계

완료 기준: 기술 선택 근거와 최소 아키텍처 확정.

## Phase 1 — Core Workspace MVP

- [ ] 기본 웹 채팅과 서버 기반 세션 저장·조회
- [ ] 대화 및 작업 이벤트 실시간 동기화
- [ ] 중앙 실행 환경과 Tailscale 연결
- [ ] 최소 인증·권한 제어
- [ ] MacBook → 모바일 → MacBook 동일 세션 이어하기 검증

완료 기준: 접속 기기가 바뀌어도 중앙 작업이 유지되고 같은 세션을 이어갈 수 있다.

## Phase 2 — Multi-Model & Template

- [ ] 외부 API 및 Ollama 연동
- [ ] Agent 프로필과 하네스 템플릿
- [ ] 공통·프로젝트 메모리와 세션 생성 시 템플릿 선택

완료 기준: 템플릿을 여러 세션에 재사용하고 API·로컬 모델을 선택할 수 있다.

## Phase 3 — Agent Execution

- [ ] 파일·터미널 도구와 Git 연동
- [ ] 장시간 작업, 명령 승인 및 취소
- [ ] 원격 Worker 도입 필요성 검증 및 필요 시 구현
- [ ] 실행 로그와 변경 사항 추적

완료 기준: AI가 실제 프로젝트 작업을 수행하고 다른 기기에서 상태·결과를 확인할 수 있다.

## Phase 4 — Scheduled Tasks & Routines

- [ ] 일회성 예약 메시지와 반복 예약
- [ ] 예약 Agent 실행과 루틴 정의
- [ ] 실행 이력, 알림, 오류 처리 및 중복 실행 방지

완료 기준: 사용자가 접속하지 않아도 예약 작업을 실행하고 결과를 조회하거나 알림을 받을 수 있다.
