# 의사결정 기록

## 현재 상태

구현 기술과 아키텍처에 관한 신규 확정 결정은 없다.

사용자가 확정한 요구사항은 [PRD §3.1](PRD.md)을 기준으로 한다. Tailscale 연결과 Ollama 활용 등의 확정 요구사항과, Mac mini 메인 서버·Next.js·PostgreSQL·OpenCode·BullMQ 등의 검토안 또는 후보를 구분한다.

## 우선 결정할 항목

- 기존 오픈소스 Fork와 자체 플랫폼 개발 비교
- 중앙 실행 및 원격 Worker의 도입 범위
- 세션 연속성의 정확한 보장 범위
- 기존 Claude Code/Codex 세션 통합 수준
- Agent 런타임 및 저장·예약 실행 기술
