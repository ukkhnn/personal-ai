# Mac mini에서 이어가기

작성: 2026-10-28. 맥북에서 확인한 실행 연결과 화면을 맥미니에서 이어 개발하기 위한 기록이다.

## 코드 가져오기

맥미니의 iCloud 밖 위치를 사용한다. 예: `~/Developer/personal-ai`. 기존 저장소가 있으면 새로 복제하지 말고 해당 폴더에서 작업 브랜치를 가져온다. 메인 병합은 사용자 승인 전까지 수행하지 않는다.

```sh
mkdir -p ~/Developer
cd ~/Developer
git clone git@github.com:ukkhnn/personal-ai.git
cd personal-ai
git switch feat/opencode-workspace
cd agent-workspace/app
npm run doctor
npm start
```

이미 복제한 경우:

```sh
git fetch origin
git switch feat/opencode-workspace
git pull --ff-only
```

Node.js 22.19 이상과 OpenCode가 필요하다. 없는 경우 전역 설치는 사용자 승인 후 진행한다. 이번 맥북 검증 버전은 OpenCode 1.18.18이다. 맥미니에서도 기존 공급자 인증과 설정을 먼저 확인한다. API 키를 저장소·대화·로그에 붙여 넣지 않는다. 이 앱은 키를 옮겨 주지 않는다.

`http://127.0.0.1:4310`에 접속하고 서버가 안내한 파일의 접속 암호를 입력한다. 맥미니의 실제 저장소 경로를 프로젝트로 연결하고 모델을 선택해 실행 템플릿을 만든다. 실행 파일과 데이터 기본 경로는 iCloud 밖 `~/.local/share/personal-ai`다.

## 무엇이 이어지고 무엇이 별도인가

GitHub로 소스·설계·검증 기록을 이어간다. 맥북의 실행 중인 작업·절대경로·OpenCode 세션이 맥미니로 자동 이전되지는 않는다. 데이터 폴더만 복사해도 실행 환경이 복원된다고 가정하지 않는다. 현재는 맥미니에서 새 프로젝트·작업을 만든다. 앞으로 맥미니를 중앙 서버로 정착시키면 클라이언트 기기만 바꾸고 같은 서버의 작업을 이어가게 된다.

현재 열어 둔 4311 포트 화면은 맥북의 임시 테스트 데이터로 작동하는 미리보기다. 테스트 작업은 실제 사용자 저장소가 아닌 임시 fixture를 사용했다. 정식 실행은 위의 기본 4310 포트 절차를 따른다.

## 완료한 확인

- 기존 OpenCode 공급자 연결을 재사용하고 기존 설정을 수정하지 않음
- DeepSeek Flash 실제 호출, 파일 변경, 셸 명령 승인, 대기열 후속 지시 처리
- 자동 테스트 9개 통과, 브라우저에서 대화·변경 탭·템플릿 모달 확인
- 자체 서버·런타임 어댑터·Git·저장 계층 분리
