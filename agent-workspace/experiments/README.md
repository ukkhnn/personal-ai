# 실험 및 PoC

기술 선택에 필요한 최소 실험의 코드, 실행 방법과 결과를 저장한다.

첫 검증 가설은 “중앙에서 관리되는 AI 세션과 실행 환경을 통해 사용 기기에 관계없이 작업을 이어갈 수 있다”이다.

실험별 하위 폴더를 만들고 목표·가설, 환경·버전, 재현 절차, 성공 기준, 결과와 한계를 기록한다. 실험 결과와 기술 채택 결정은 구분하고, 결정은 [DECISIONS.md](../DECISIONS.md)에 남긴다.

실행한 실험: [M3 Ollama 연결 및 기록 누적](ollama/README.md). 2026-11-15 실제 Qwen 3B/7B 응답·실패·평가·복원을 확인했다. 27B 확장은 Ollama 업데이트와 설치 대기다.
